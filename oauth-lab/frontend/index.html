Keycloak · API7 OAuth2 실습

Access Token을 받고, API7이 API 접근을 허용하는지 확인합니다.

1. Access Token 받기

Keycloak에서 alice 또는 admin으로 인증합니다. 비밀번호는 이 페이지에 입력하지 않습니다.

아직 받은 토큰이 없습니다.
토큰은 메모리에만 보관합니다. 새로고침하면 사라집니다. 토큰 지우기는 Keycloak 세션 종료나 서버의 토큰 폐기가 아닙니다.

2. API7에 요청하기

요청 결과가 여기에 표시됩니다.
예상 결과: 일반 API는 두 계정 모두 200 · 관리자 API는 alice 403, admin 200 · 토큰 없음 401

이 화면은 OAuth2 요청용 클라이언트입니다. 실제 API7 관리 콘솔은 별도로 엽니다.
