# 현재 사용자 화면

[current/](current/)에는 2026-10-15 FinAccess 사용자 앱 캡처 두 장이 있습니다. [검증 결과와 화면 해설](../current/06-verification.md)을 함께 읽습니다.

- USER 토큰으로 API7과 FinAccess를 거쳐 200을 받은 화면
- ADMIN 전용 토큰으로 USER API를 호출해 API7에서 403을 받은 화면

이 캡처는 API7 제품 관리 UI가 아닙니다. 현재 아키텍처는 [아키텍처·시퀀스 문서](../current/02-architecture.md)의 도식을 사용합니다.
