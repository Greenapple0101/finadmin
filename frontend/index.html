FINACCESS + FINADMIN

같은 로그인, 서로 다른 API 권한

Keycloak에서 로그인한 뒤 API7 Enterprise가 토큰과 역할을 확인합니다. FinAccess와 FinAdmin도 각자 토큰과 역할을 다시 검사합니다.

1. 사용자 로그인

alice는 일반 사용자, admin은 앱 관리자입니다. 비밀번호는 데스크탑의 로컬 인증 문서에 있습니다.

회사 명부 계정으로도 비교해 보세요. ldap-alice는 일반 직원, ldap-admin은 관리자입니다. 같은 로그인 버튼을 사용합니다.

로그인하지 않았습니다.

2. 권한에 따른 응답 확인

일반 사용자도 내 정보는 조회할 수 있습니다. 관리자 요약은 admin 역할이 있어야 조회됩니다.

버튼을 눌러 요청 결과를 확인하세요.

아직 요청하지 않았습니다.
401: 유효한 토큰이 필요합니다. · 403: 요청에 필요한 권한이 없습니다. · 200: 조회 성공.
요약의 숫자는 샘플입니다. 실제 고객정보나 금융 거래를 사용하지 않습니다.
